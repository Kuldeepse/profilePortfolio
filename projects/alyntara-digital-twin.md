# Alyntara Digital Twin

**Status:** Foundational development; live integration and demonstration not yet validated.

## Purpose
Agentic multistep workflow execution using task lifecycle, persistence, application adapters, approval state and audit records.

## Engineering work
Foundational task models, adapter registry, runtime state and persistence, approval control patterns and focused tests.

## Current limitations
A complete live Gmail/Calendar workflow, production readiness and publicly accessible demonstration remain unverified. The previously shared Vercel prototype URL was reported unavailable, so it is not linked as a working demo.
