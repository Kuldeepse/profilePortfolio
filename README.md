## What I Work On

- **Agents and LLMs:** prompting, tool calling, workflow orchestration, multimodal interaction and evaluation.
- **Backend and integration:** APIs, authentication, application adapters, persistent task state and cloud infrastructure.
- **Product lifecycle:** problem discovery, MVP definition, prioritisation, testing, iterative improvement and operational handover.
- **Quality and safety:** functional/regression testing, CI validation, security and privacy controls, human review and release gates.

## Engineering and Product Approach

**Discover → Design → Build → Evaluate → Iterate → Release when validated.**

I aim to make decisions based on observable behaviour: whether a user journey works, whether an integration is reliable, what a test actually proves, and what still prevents production readiness.
