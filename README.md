## What I Work On

## Engineering and Product Approach

**Discover → Design → Build → Evaluate → Iterate → Release when validated.**

I aim to make decisions based on observable behaviour: whether a user journey works, whether an integration is reliable, what a test actually proves, and what still prevents production readiness.
